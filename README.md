# Ali Ioli — Authentic Spanish Restaurant & Tapas Bar

A modern, responsive, and luxury single-page website for **Ali Ioli**, an authentic Spanish restaurant located on Goodwin Street, Finsbury Park, London.

Generated directly from Stitch project screen `4082abfa801849dba51be946b4ba3a2f`.

---

## 🇪🇸 Features & Enhancements

1. **Cinematic Hero**:
   - High-definition ambient Spanish restaurant photography with Iberian lighting overlays.
   - Dynamic proof bar showcasing Google (4.9★), TripAdvisor (5.0★), and TheFork (9.8/10) ratings.
   - Dual Call-to-Actions for instant table bookings and experience discovery.

2. **Our Story & 3 Pillars**:
   - Asymmetric heritage visual with rotating `100% Homemade` floating badge.
   - Core philosophy: *Hearty & Homemade*, *Inclusive Dining (Vegan/Vegetarian)*, and *Warm London Hospitality*.
   - Kitchen signature team badge.

3. **Interactive Menu & Category Filtering**:
   - Filter tabs: **All Highlights**, **Authentic Tapas**, **Traditional Classics**, **Vegan Tapas**, and **Vinos & Sangría**.
   - Sizzling Gambas al Ajillo, 36-month cured Jamón Ibérico de Bellota, Pulpo a la Gallega, Pimientos de Padrón, Artisanal Churros con Chocolate, and Spanish Bodega Wines.
   - **Carta Completa Modal**: Interactive pop-up menu detailing cold tapas, hot tapas, paellas, desserts, and wines with dietary badges (V, VG, GF).

4. **Restaurant Experience ("More Than A Meal")**:
   - 3 Bento cards highlighting the vibrant Tapas Bar, family warmth, and Finsbury Park sanctuary.
   - Live opening hours indicator (`Open Tue - Sun from 12:00`).

5. **Verified Guest Reviews**:
   - Testimonials from London locals and food critics across Google, TripAdvisor, and TheFork.

6. **Interactive Reservation Suite ("Your Table Awaits")**:
   - Party size selector (1 to 7+ guests).
   - Quick date presets (*Today*, *Tomorrow*, *Friday*, *Saturday*) plus date picker.
   - Seating area options (*Main Dining Room* vs *Tapas Counter*).
   - Time slot buttons (17:30 to 21:15).
   - **Booking Voucher Confirmation Modal**: Generates instant reference code with full booking breakdown upon submission.

7. **Visual Monograph Gallery & Lightbox**:
   - Staggered masonry photo grid with hover captions.
   - Full-screen interactive lightbox viewer on click.

8. **Location & Contact**:
   - Transit guide (2-min walk from Finsbury Park tube station).
   - Direct call button and Google Maps directions link.
   - Map card with animated pulsating location pin.

9. **Mobile Responsive**:
   - Fixed header with blur backdrop.
   - Slide-out off-canvas mobile drawer menu.
   - Smooth scroll spy tracking active navigation.
   - Floating back-to-top button.

## 🚀 How to Run Locally

You can preview the website using any local static file server or by opening `index.html` in your browser.

### Option 1: Quick preview with Node
```bash
npm start
# or
npx serve . -l 3000
```
Then visit `http://localhost:3000`.

Double-click [index.html](file:///c:/Users/hrish/OneDrive/Documents/Hrishabh%20Ranjan/Fiver/Ali%20Oili/index.html) or open it with Google Chrome / any modern browser.
